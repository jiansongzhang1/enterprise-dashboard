# 订阅简报 · 运营总览截图（后端截图）

发送订阅时，后端用本机无头 Chrome 打开运营总览页（订阅的站点 + 查询条件）截图，上传 Lark，放进订阅卡片发到群。截图失败照常发文字卡片，卡片里写「運營總覽截圖生成失敗，請在 Yata 中查看」，原因记日志、管理后台预览里显示。

代码：`com.fivetech.dashboard.subscription.snapshot`（`SubscriptionSnapshotService`、`HeadlessChrome`、`Cdp`），令牌签发 `framework.web.service.SnapshotTokenIssuer`，Lark 上传 `LarkClient.uploadImage`。

## 流程

1. 拼地址：`page-url` ＋ 订阅的查询条件（`snapshot_query`）。为空时按统计范围生成，与卡片同一区间：
   - 今日：`range=today&gran=hour&cmp=previous-period`
   - 昨日：`range=yesterday&gran=hour&cmp=previous-period`
   - 近 7 / 30 日：`range=custom&gran=day&from={from}&to={to}&cmp=previous-period`（不含发送当天）
   - 查询条件与 `page-url` 里可用 `{from}` `{to}`（统计区间首尾日期，to 为最后一天）、`{site}`；管理后台可直接贴整条页面地址，只取 `?` 后面的部分。
2. 签令牌：给截图帐号（`username`）在进程内签发临时令牌（不走登录接口、密码、GA），默认 180 秒有效、不续期、不进在线用户，截完立即作废。权限按该帐号当前的角色加载。
3. 截图：每张一个独立的浏览器上下文；写 cookie（`token-cookie`）/ localStorage（`token-local-storage-key`、`local-storage`）→ 打开页面 → 等页面就绪（load、网络空闲 0.8 秒、`ready-selector` 出现、`busy-selector` 消失，跳到登录页立即报错）→ 隐藏 `hide-selector` → 撑开到整页高度再等一轮 → 截 PNG（或只截 `capture-selector`）。
4. 上传：`POST /open-apis/im/v1/images`（`image_type=message`）拿 `image_key`，卡片在指标下方加图片（点开可放大）。

全局同一时间只截一张，排队超过 120 秒本次不带截图；浏览器常驻，截 50 张重启一次。

## EC2 准备（Ubuntu 24.04，x86_64）

```bash
sudo apt-get update
sudo apt-get install -y fonts-noto-cjk fonts-noto-color-emoji
wget -q -O /tmp/chrome.deb https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo apt-get install -y /tmp/chrome.deb
google-chrome --version
fc-list :lang=zh | head -2
```

不要用 `apt install chromium-browser`（Ubuntu 24.04 上是 snap 版，后台服务下容易出问题）。服务以 root 运行时加 `DASHBOARD_SNAPSHOT_CHROME_ARGS=--no-sandbox`。

建议给服务的 systemd 单元加内存上限，防止浏览器把内存用光（机器没有 swap）：`MemoryMax=5G`。

## 配置（`application.yml` 的 `dashboard.subscription.snapshot`）

| 配置 | 环境变量 | 说明 |
| --- | --- | --- |
| `enabled` | `DASHBOARD_SNAPSHOT_ENABLED`（默认 false） | 总开关；管理后台的「總覽截圖」开关据此可用 |
| `chromium-path` | `DASHBOARD_SNAPSHOT_CHROME`（默认 `/usr/bin/google-chrome`） | 浏览器可执行文件 |
| `chromium-args` | `DASHBOARD_SNAPSHOT_CHROME_ARGS` | 额外参数，逗号分隔（root 运行加 `--no-sandbox`） |
| `username` | `DASHBOARD_SNAPSHOT_USER` | 截图帐号，建议只读的专用帐号 |
| `token-ttl-seconds` | — | 临时令牌有效期，默认 180 |
| `page-url` | `DASHBOARD_SNAPSHOT_PAGE_URL` | 运营总览页地址，如 `https://d3ajrxvlugsarb.cloudfront.net/zh-TW/overview` |
| `token-cookie` / `token-local-storage-key` | `DASHBOARD_SNAPSHOT_TOKEN_COOKIE`（默认 `Admin-Token`）/ `DASHBOARD_SNAPSHOT_TOKEN_LS_KEY` | 前端存登录令牌的位置，按前端实际填 |
| `local-storage` | — | 额外的 localStorage 键值，值里可用 `{site}` `{token}`（如前端记住的当前站点） |
| `width` / `height` / `max-height` / `scale` | — | 1280 × 900，最高 6000，像素比 1.5 |
| `capture-selector` / `ready-selector` / `hide-selector` | `DASHBOARD_SNAPSHOT_*_SELECTOR` | 只截的区域、就绪元素、截图前隐藏的元素（CSS 选择器） |
| `busy-selector` | — | 加载中的标志，默认 Element / Ant Design 的 loading、骨架屏 |
| `timeout-seconds` / `queue-seconds` / `restart-after` | — | 45 / 120 / 50 |

数据库：`sql/release_next_postgresql.sql` ⑨（`snapshot_enabled`、`snapshot_query`）。Lark 机器人要开通上传图片的权限。

## 接口变化

- `GET /system/subscriptions/meta` 多 `snapshot: { enabled, queryHint }`。
- 订阅的新增、修改、列表、详情多 `snapshotEnabled`（boolean）、`snapshotQuery`（string，保存时规范化：可贴整条地址；只允许字母、数字和 `_ . ~ = & % : , + { } -`，最多 500 字，否则 400 `data.fields.snapshotQuery`）。
- 预览多 `snapshot: { image: "data:image/png;base64,…", url, error }`（预览不上传 Lark）；立即发送、测试发送、定时发送都会截图并上传。前端这三个请求的超时放宽到 3 分钟。

## 安全与注意

- 截图用的是截图帐号的权限，不是订阅创建人的。订阅只能选创建人有权限的站点；截图帐号请只给运营总览的查看权限和需要的站点，不要用超级管理员。
- 令牌只在本机进程与浏览器之间传递，不写日志；日志只记页面地址（不含令牌）。
- 截图页面在发送那一刻取数，今日范围会包含发送时正在进行的小时，可能和卡片文字（截至发送整点）差几分钟的数据。
- 前端改版（地址参数、登录态存放位置、页面结构）可能导致截图失败，上线后用「預覽」看一次截图。
